# Scoop Bucket for Antigravity eXtension (`agx`)

Official Scoop bucket for installing [**Antigravity eXtension (`agx`)**](https://github.com/imsaba16/agx) on Windows.

---

## Installation

Add the bucket to Scoop:
```powershell
scoop bucket add agx https://github.com/imsaba16/scoop-bucket
```

Install `agx`:
```powershell
scoop install agx
```

---

## Verification

```powershell
agx --version
# agx 1.0.0-rc.1
```

---

## Upgrading

To update to the latest release:
```powershell
scoop update agx
```
